## 3. 动线与尺度逻辑

- **人流主线**：主路 A → 斑马线 A → 便利店入口（自动门）→ 店内；候车亭 ↔ 站台 ↔ 电车为次级动线。
- **街角转折**：便利店占据 L 形路口内角，玻璃幕墙沿两路展开，转角处形成视觉焦点（贩卖机+雨伞架+花盆簇拥）。
- **疏密节奏**：西侧「车站+樱花+车区」偏疏朗开阔；东南「店前道具群」饱满密集；轨道纵深提供背景层次。
- **尺度**：建筑 7.5m 面宽、树高 5~8m、人视目标点 y≈1.2，符合微缩模型观赏比例（默认相机半径 ~34）。

## 4. 光照与氛围规划

- 太阳方向：西偏南高空（方位约 -X/+Z 之间），暖白主光 + 冷色补光 + 半球天光；
- 阴影投向东侧，强化街角体积感；
- 远景雾 + 低强度 Bloom 形成春日空气光晕。
